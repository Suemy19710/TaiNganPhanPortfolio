# Tai Ngan Phan — Portfolio

Personal portfolio for Tai Ngan (Tiffany) Phan, International Communication Management student at The Hague University of Applied Sciences, looking for a marketing & communication internship.

Built with React 18 + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

The static site is output to `dist/` and can be deployed to Netlify, Vercel or GitHub Pages.

## Editing content

All text (projects, experience, skills, contact details) lives in `src/data/content.js`.
Images are in `src/assets/`. Colours and fonts are CSS variables at the top of `src/index.css`.
